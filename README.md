# USSD 110 — HTML to Android APK via GitHub Actions

## ماذا يفعل هذا المشروع؟
واجهة عربية تجريبية تعمل دون إنترنت وتحاكي شاشة الاتصال والقوائم التي تظهر داخل التطبيق عند إدخال `*110#`. لا يتصل بشبكة الاتصالات ولا ينفذ تحويلات أو يستعلم عن رصيد حقيقي.

## إنشاء APK من الهاتف باستخدام GitHub
1. نزّل ملف ZIP وفك ضغطه.
2. أنشئ مستودعًا جديدًا في GitHub (Repository) من المتصفح أو تطبيق GitHub.
3. ارفع **محتويات** هذا المجلد إلى جذر المستودع، وليس ملف ZIP نفسه. تأكد من رفع المجلد المخفي `.github/workflows/build-apk.yml`.
4. افتح تبويب **Actions** في المستودع.
5. اختر **Build Android APK** ثم اضغط **Run workflow**. إذا بدأ البناء تلقائيًا بعد رفع الملفات، يمكنك انتظار اكتماله.
6. بعد نجاح المهمة، افتح تشغيل البناء الأخضر وانزل إلى **Artifacts**.
7. نزّل `USSD-110-debug-APK`، ثم فك ضغط ملف artifact وستجد `app-debug.apk` لتثبيته على هاتفك. قد تحتاج السماح بالتثبيت من هذا المصدر.

## ملاحظات
- الناتج APK تجريبي (debug) قابل للتثبيت للاختبار؛ ليس إصدار متجر موقّعًا للنشر.
- رمز `*110#` يعمل داخل لوحة الاتصال التي يوفرها التطبيق فقط. تطبيق ويب لا يستطيع التقاط الرمز من تطبيق الهاتف الأصلي.
- جميع الواجهات محلية ولا تحتاج إنترنت بعد تثبيت التطبيق.
